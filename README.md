# matrix

A repository called "matrix" for experiments and projects.

## Workflow

- Before committing/pushing changes: summarize what will be committed (e.g., key files touched) and verify nothing looks like a secret.
- Before pushing: confirm you are not in a detached HEAD state (i.e., `git status -sb` should not show `HEAD (no branch)`); if you are detached, fix it (e.g., switch to the intended branch and cherry-pick the detached commit) before pushing.
- After pushing changes: include the direct GitHub link(s) to any PDF(s) that were added/updated (e.g., `https://github.com/<org>/<repo>/blob/<branch>/<path>.pdf`).
